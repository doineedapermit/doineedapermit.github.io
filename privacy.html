Privacy Policy

Last updated: 16 November 2026

This policy covers the Sallaiti Studio publishing tool, an internal application used only by Sallaiti Studio.

What the tool accesses

With the channel owner's permission (Google OAuth), the tool uses the YouTube Data API to upload and schedule videos on Sallaiti Studio's own YouTube channel, and the YouTube Analytics API to read that channel's own statistics (views, watch time, retention).

What we do not do

  • We do not collect personal data from viewers or any other users.
  • We do not sell, share or transfer any Google user data to third parties.
  • We do not use Google user data for advertising.

Storage and security

The access credential is stored privately and used only by our own publishing tool. Analytics figures are kept in our private project files for planning future videos.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
